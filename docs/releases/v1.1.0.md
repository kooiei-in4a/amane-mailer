## Positioning

- Minor release on the 1.x line. Ships ACS Delivery Report bounce ingestion
  (Storage Queue Pull), tenant suppressions, setup entry / diagnostic CLIs, and
  production deploy wiring for setup modes 4 and 5.
- **Additive HTTP contract change.** Consumers may observe the new delivery
  error code `RECIPIENT_SUPPRESSED` on status / attempts; request schemas are
  unchanged. `Amane.Mailer.Contracts` and OpenAPI `info.version` move to
  `1.1.0`.
- Requires SQLite migration `011_bounce_ingestion.sql` (not present in 1.0.x).
  Backup before upgrade; downgrade to 1.0.x without a data migration path is
  not supported once 011 has been applied.
- Event Grid Push webhook (#304) and Consumer “bounced Enotification
  (ADR 0020 D-11) remain out of scope.

## Included changes since v1.0.1

### Bounce ingestion / suppression

- **#301**  EMigration 011: `provider_event_inbox`, `bounce_events`,
  `mail_suppressions`.
- **#302**  EIngestion worker: parse ACS Delivery Reports, correlate, record
  bounce history, upsert suppressions.
- **#303**  ESend-time suppression with `RECIPIENT_SUPPRESSED` and
  `mail_suppressed_sends_total`.
- **#305**  EAzure Storage Queue Pull transport
  (`MAILER_BOUNCE_INGESTION=queue`).
- **#306**  EAdmin bounce visibility, suppressions list (view-only), bounce
  runbooks / metrics.
- **#400**  E`db suppressions remove` CLI with audited removal.

### Setup / operations

- **#424**  ESingle setup entry guide (JA/EN) with mode taxonomy.
- **#425**  ERead-only `setup doctor`.
- **#426**  EStaging-only `admin provider test-acs-send`.
- **#427**  ERead-only `setup check-event-grid`.
- **#428**  EStaging-only `setup verify-delivery-report`.
- **#435**  EProduction-confirmed `register-acs` (mode 4 Available).
- **#436**  EDeploy compose bounce Queue wiring (mode 5 Available).
- **#437**  E`setup-entry-guide` marked `implemented`.

### Admin reliability

- **#391**  EMonotonic / interval-throttled session touch; absolute cookie
  lifetime; idle expiry from `admin_sessions` only.

### Contracts / OpenAPI

- `Amane.Mailer.Contracts` and OpenAPI `info.version` aligned on `1.1.0`.
- Additive delivery error code `RECIPIENT_SUPPRESSED` (#303).
- Migration `011_bounce_ingestion.sql` required for bounce / suppression tables.
  Present in the published image at `/app/Data/Migrations/011_bounce_ingestion.sql`.

### Out of scope (explicit)

- Event Grid Push webhook (#304).
- Consumer bounced notification (ADR 0020 D-11).
- Azure resource auto-creation.
- Real bounce as a normal setup completion criterion.
