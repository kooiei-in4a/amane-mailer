## Easy Setup / Admin notes (operator-facing)

- **Setup vs upgrade:** Easy Setup targets fresh or managed first-time setup.
  Existing Manual / Hardened deployments upgrade by pulling the new image and
  applying SQLite migrations in the normal runtime path.
- **Admin access profiles:** Local Development and Production HTTPS profiles as
  documented in setup guides. If Admin cannot be established safely, Admin
  remains disabled.
- **Non-interactive Admin bootstrap is forbidden.**
- Release Production operational verification is product-artifact qualification,
  not end-user environment verification.
