## Easy Setup scope (operator-facing)

- Easy Setup provides a localhost-bound host assistant (Web + terminal /
  non-interactive) that generates / applies a managed compose layout for
  modes 1–4. It does **not** replace Manual / Hardened documentation paths.
- **Setup vs upgrade:** Easy Setup targets fresh or managed first-time setup.
  Existing Manual / Hardened deployments **upgrade** by pulling the new image
  and applying SQLite migrations in the normal runtime path. Easy Setup is
  **not** a silent re-bootstrap of an already-running Admin deployment.
- **Admin access profiles:**
  - Local Development: Admin may be enabled under the documented local profile.
  - Production HTTPS: Admin may be enabled only when the documented Production
    HTTPS Admin access profile is satisfied.
  - If the Admin path cannot be established safely, Admin remains **disabled**.
- **Non-interactive Admin bootstrap is forbidden.** Typed Admin bootstrap
  ownership / lease / CAS (#459) does not authorize unattended Admin creation
  outside the documented interactive / exact-delta paths.
- **Release Production operational verification** (#456 / release gates) is
  **product artifact qualification**. It is **not** end-user environment
  verification and does not claim customer Production readiness.
