## Operational limitations

- `202 Accepted` means the request was persisted; it does not mean provider
  delivery has completed.
- Delivery is at-least-once.
- SQLite production deployment is single-node / single-replica.
- Admin UI is disabled by default, internal-network-oriented, and experimental.
- Back up the SQLite DB and tenant configuration before upgrade or migration.
- ACS live sending requires explicit ACS configuration, a live-sending-enabled
  tenant, and an approved sender/domain.
