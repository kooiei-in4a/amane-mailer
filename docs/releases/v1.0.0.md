## Included changes since v0.9.2

### Reliability / security

- Reject invalid UTF-8 request bodies with `400` (#343).
- Reject Admin `ALLOW_HTTP` outside Development; register webhook client when
  worker is disabled (#341).
- Classify schema probe failures separately from `schema_not_ready` (#342).
- Dispose SQLite connections on open / PRAGMA init failure (#344).
- Judge webhook delivery from response headers without buffering the body (#370).

### Operations / configuration

- Strict boolean and port parsing (#358).
- Mailpit SMTP host/port startup validation when in use (#356).
- Centralized startup options validation catalog (#351).
- Rename webhook reconcile batch size to `ReconcileBatchSize` with deprecated
  `BatchClaimSize` alias (#353).

### Admin / Worker

- Require tenant scope on Admin mail attempt listing (#357).
- Await Admin credential sync before route mapping (#350).
- Admin extensions and mail-request endpoint module splits (#349, #348).
- Worker `InflightTracker` async signal (#354).
- CLI Ctrl+C cancellation for long-running commands (#347).

### Quality / SDK / docs

- MailRequest field-inventory CI gate (#352).
- Formatter / staged analyzer gates (#359).
- Python / TypeScript SDK `scheduled_at` builders (#346).
- ADR 0016–0019 (internal typing, webhook first-wins, sequential concurrency
  deferral, SQLite single-process boundaries).

### Contracts / OpenAPI

- `Amane.Mailer.Contracts` and OpenAPI `info.version` aligned on `1.0.0`.
- OpenAPI documents strict UTF-8 rejection for create / reschedule bodies.
- No new consumer DTO fields removed; no new SQL migration in this release.

## Operational notes (release checklist)

- `202 Accepted` means Mailer persisted the request; it is not provider delivery
  completion.
- Delivery is at-least-once.
- SQLite deployments remain single-node / single-replica (ADR 0019).
- Admin UI stays disabled by default, internal-network, experimental.
- Upgrade: no new SQL migration beyond v0.9.2 migration 010; back up DB and
  tenant config before upgrade.
- ACS live sending still requires explicit ACS config, secret file in
  Staging/Production, `live_sending=true` tenant, and approved sender/domain.
